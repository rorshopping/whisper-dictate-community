# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting for this repository when available. Do not open a public issue containing exploit details, credentials, personal data, or a reproducible security compromise.

Include:

- affected version or commit;
- platform and Python version;
- reproduction steps;
- impact and any safe workaround you found.

Please do not include real microphone recordings, transcription histories, API keys, or model files.

## Scope

Audio processing is intended to remain local. Please report any code path that uploads audio, exposes user data, executes untrusted model code, or weakens model/hash verification.

This repository is provided without warranty. Security fixes are reviewed through the normal public contribution process after a private report is received.
