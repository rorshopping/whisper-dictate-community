# Code of Conduct

We want a welcoming, respectful, and constructive community.

- Be kind and assume good intent.
- Critique code and ideas, not people.
- Avoid harassment, threats, discrimination, and personal attacks.
- Keep discussions focused and technically relevant.
- Do not publish another person's private information, recordings, credentials, or local vocabulary.

Maintainers may edit or remove comments, issues, or code that violates these expectations. Report concerns privately through the repository's security/contact channels when appropriate.
